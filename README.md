# Bow Sensor Fault Detection & Alarm System

## Project Overview

This project is an AI-driven Bow Sensor Fault Detection and Alarm System developed for marine applications.

The system continuously monitors ultrasonic sensor signals and detects abnormal operating conditions using anomaly scoring and fault classification techniques.

The dashboard simulates real-time sensor behaviour and provides visual fault analysis for different sensor failure modes.

---

## Features

### Real-Time Monitoring
- Signal Strength Monitoring
- Echo Return Time Analysis
- Distance Measurement
- Noise Level Tracking
- Fault Score Calculation

### Fault Detection Modes
1. Signal Noise / Interference
2. Echo Drift (Temperature Shift)
3. Weak Signal (Transducer Fouling)
4. Signal Dropout
5. Spike / Transducer Fault

### Visualization
- Live Waveform Charts
- Feature Trend Graphs
- Alarm Log Monitoring
- Fault Severity Indicators
- Dedicated Fault Dashboards

### Data Recording
- Real-Time Data Logging
- CSV Export Functionality
- Timestamp Tracking
- Sensor Parameter Storage
